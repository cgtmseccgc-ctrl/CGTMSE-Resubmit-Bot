# CGTMSE Resubmit Desk v1.6.2

Windows Python bot for returned first-instalment claims on https://inter.cgtmse.in

## Download

On GitHub: **Code → Download ZIP**

https://github.com/cgtmseccgc-ctrl/CGTMSE-Resubmit-Bot/archive/refs/heads/main.zip

Unzip, then double-click `run.bat`. Use a new folder.

## What 1.6.2 changes

The desk waits longer after OK, Submit, Accept, and the checker list so the portal can finish loading.

## Checker

- If maker already sent the claim, checker still looks for it
- Opens the D/U list once, ticks ACCEPT on every Excel claim on that page, Save once
